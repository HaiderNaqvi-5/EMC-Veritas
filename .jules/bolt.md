## 2026-10-04 - Openpyxl Read-Only Generator Limitation\n**Learning:** When using `openpyxl.load_workbook(..., read_only=True)`, the generator returned by `sheet.iter_rows()` can only be traversed once. If you need to loop over the rows multiple times (e.g., to bulk-fetch IDs before processing), you must evaluate the generator into a list first.\n**Action:** Always wrap `iter_rows()` in a `list()` if the data needs to be accessed more than once during an import process.
